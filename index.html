01 / Write the idea

One rule. One small step.

Function application becomes substitution:

\[ (\lambda x.\, e)\,v \;\longrightarrow_{\beta}\; e[x \coloneqq v] \]

For example, \((\lambda x.\, x + 1)\,2 \longrightarrow 2 + 1 \longrightarrow 3\).

Math and fonts are bundled locally. No CDN required.

Press the right arrow once to reveal the example. KaTeX handles both display and inline math.

02 / Show the idea

Make the step visible.

Advance to animate each step. Go back to reverse it.

Use the same Next/Back controls as the rest of the talk. The first advance substitutes 2 for x; the second computes 3; the third moves to the next slide. Back reverses these steps. Fragment labels in the HTML correspond to GSAP timeline labels in src/animations/reduction.ts.
